# 🌐 WordPress Product Landing Page (GeeBees)

---

## 📌 Project Overview
This project is a fully responsive product landing page developed using WordPress from scratch without using any pre-built templates. The goal was to create a clean, modern, and conversion-focused design for a tea brand website.

---

## 🚀 Features
- Fully responsive landing page design  
- Custom-built layout without using templates  
- Clean and modern UI/UX  
- Product-focused design for better user engagement  
- SEO optimized structure  
- Fast loading and performance optimized  
- User-friendly navigation  

---

## 🛠️ Tech Stack
- WordPress
